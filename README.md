# zeb

Documentation UML du projet de fin d’études **CLÉOPÂTRE — Espace Santé Beauté**
(plateforme de e-commerce / parapharmacie).

## Contenu

- [`diagrammes/`](diagrammes/README.md) — **18 diagrammes UML 2.x** (8 classes +
  10 séquences) en sources PlantUML, SVG titrés et PNG haute résolution,
  avec un design system unique, prêts à insérer dans le rapport PFE.

Voir le [README du package diagrammes](diagrammes/README.md) pour la
nomenclature, la correspondance avec le code source et la méthode de
régénération.
